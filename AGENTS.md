# Project entry points

- `src/extension.ts` registers the VS Code custom editor and owns host clipboard, export destinations, and the webview boundary. `src/SqliteDocument.ts` owns document lifecycle, request serialization, native save, and recovery.
- `src/SqliteDatabase.ts` owns schema inspection, lossless typed values, queries, staged editing, transactions, conflict checks, and consistent database snapshots. `src/SqlQuery.ts` owns isolated SQL reads and `src/CsvImport.ts` owns CSV parsing and mapping. Cross-layer values and requests are defined in `src/protocol.ts`.
- `src/webview/grid.ts` mounts the browser interface. `src/webview/SqlWorkspace.ts` owns the SQL editor and results; `DatabaseTools.ts` owns CSV, schema, and maintenance dialogs. `SearchPanel.ts` owns the shared Find/Replace modal dialog, `SqlTextSearch.ts` owns SQL draft matching and native-editor replacements, and `src/CellSearch.ts` owns table matching and search snapshots. Other webview modules own table navigation, editing, and styling.
- Ordinary edits remain staged until Ctrl/Cmd+S commits all pending changes in one transaction. Table switching preserves pending changes. Undo/Redo cover the current unsaved editing session; Save and Revert establish a new baseline. Data sorting and displayed column order never rewrite database structure.
- SQL writes and structure changes commit immediately in a transaction, require no staged edits, and establish a new undo baseline. Read queries use a separate read-only connection and observe committed data; cancellation bypasses the document queue.
- Find/Replace follow the active tab: table cells in Data, SQL source text in SQL Query; query results stay read-only. Add record is available in the Data menu and row-number context menu. Column add/rename/drop dialogs preview native ALTER TABLE SQL and write only after Execute.
- In Data, Ctrl/Cmd+F and Ctrl/Cmd+R open one non-modal panel at the top right of the editor (it flips to the bottom to avoid covering a located match); the grid and SQL editor stay usable, and new selections update the Selection scope. Its Replace checkbox controls whether replacement fields/actions are shown. Whole table ignores current filters and covers every page; Selection captures exact current-page key/column pairs, including sparse cells. Invalid selections must not silently expand scope. Find is read-only; Replace changes editable text cells through previewed staging, either all at once or one match at a time with skipping. Regex is opt-in and supports numbered capture-group replacement.
- Preserve integer precision, NULL versus empty strings, read-only generated/BLOB cells, view/virtual-table restrictions, and optimistic conflict detection. Never use displayed row numbers as database identities.
- Run `npm run typecheck`, `npm test`, and `npm run build` after implementation changes. UI changes also require `npm run test:ui`, with Chromium Headless Shell installed through `npx playwright install chromium --only-shell`.
- `npm run package` creates a VSIX for the current OS and architecture and includes the SQLite Node-API binary. Validate native dependency inclusion before distribution. Build each platform's package on its matching platform.
- `npm run sample` creates `examples/sample-workbench.sqlite` with 12,000 orders, 24,000 order items, related tables, views, and typed edge cases. `examples/README.md`, `queries.sql`, and CSV files provide pagination, query, and import exercises. Existing sample databases are preserved. Examples are excluded from packages.
- Use headless checks only. Do not start, display, focus, activate, reload, close, or reopen desktop VS Code, extension host, or browser windows during automation. Install updates through the background CLI; the user chooses when to reload. A desktop session needs explicit authorization.
- English is the default for interface text, documentation, source comments, and examples. Simplified Chinese remains an optional interface/documentation language; preserve intentional Unicode fixtures and translation dictionaries.
- Keep LICENSE, package metadata, and English/Chinese README license statements consistent with AGPL-3.0-only.
