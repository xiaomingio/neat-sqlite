# Changelog

## 0.1.1

- Build and verify native SQLite packages for Windows, macOS, and Linux on x64 and ARM64.
- Automate release packaging and Marketplace publishing with GitHub Actions.

## 0.1.0

- Initial public release for macOS on Apple Silicon.
- Browse tables and views with pagination, multi-column sorting, column filters, and exact SQLite values.
- Stage edits, inserts, deletes, CSV imports, and replacements across tables, then save them in one transaction.
- Query committed data with SQL completion, query history, saved queries, and CSV exports.
- Inspect and change table structure, follow foreign keys, and create consistent database snapshots.
- Follow a step-by-step Quick guide with highlighted controls. Skipping shows how to reopen it from the ? button.
- Support light and dark themes and English and Simplified Chinese interfaces.
